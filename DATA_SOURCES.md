# Данные и модели SignTalk AI

Проверено 17.11.2026. Словарь интерфейса и язык жестов — разные параметры.

## KRSL10 — активный местный пилот

Источник: https://github.com/kurshakuz/krsl-recogniton, commit `679ffe14184c6a374b2d8a3daeffabbe99e9bc6d`.
Вход: `sign-prediction/V2-videos-5signers-isolated-signs-out/Absolute/*/*.txt`. Страница первичного исследования: https://krslproject.github.io/krsl20/ ; статья https://aclanthology.org/2020.lrec-1.745/ .

Это опубликованные координаты 21 точки руки (x,y), а не новые записи команды. В копии источника найдено 5229 файлов; после фильтра качества используются 5198. Токены рук нормализуются по запястью и расстоянию до среднего пястного сустава, отражаются к общей ориентации; по каждому признаку берутся среднее, стандартное отклонение, минимум и максимум. Вектор имеет 168 значений. StandardScaler обучен только на P1/P2/P3, далее MLP 168→96→10 (ReLU), фиксированный random_state=42. Достигнут лимит 160 итераций; оптимизатор сообщил о неполной сходимости. Не утверждаем оптимальность архитектуры.

Исходные 20 классов объединены по лексеме: `gde/gdeq`, `kak/kakq`, `kakoi/kakoiq`, `kogda/kogdaq`, `kotoriy/kotoriyq`, `kto/ktoq`, `kuda/kudaq`, `skolko/skolkoq`, `what/whatq`, `zachem/zachemq`. Вопрос/утверждение по лицу не распознаётся. Контрольные примеры — первые по пути записи P5 каждого класса, а не подбор удачных предсказаний. Публично поставляются агрегированные признаки этих примеров и fixture для проверки препроцессора, не видео участников и не весь датасет.

P1/P2/P3: train 3614; P4: validation 785; P5: test 799. Test top-1 70,0876%. Порог 0,8 задан как рабочий порог отказа, без калибровки неизвестных жестов; coverage 81,2265%, accepted accuracy 77,6579%. Полный отчёт: `web/public/models/krsl/report.json`. Реестр всех использованных файлов с хешами: `docs/krsl/training-manifest.json`.

Модель обучена в рамках этой работы, экспортирована в ONNX. Различие скейлера/MLP sklearn и ONNX на десяти тестовых векторах: max probability error около 3,3e-7. Точность с новой камерой и новым Holistic не измерена. Один тестовый человек не обеспечивает широкую внешнюю валидацию. Устаревший upstream детектор не тождественен современному Holistic.

Upstream репозиторий содержит Apache 2.0, копия — `third_party/krsl/LICENSE`. У страницы первичного датасета нет отдельной ясно указанной лицензии данных; нельзя объявлять её MIT или автоматически переносить лицензию статьи на все видео. Для дальнейшего публичного распространения исходного корпуса следует уточнить условия у авторов. Весь корпус и видео в архив не включены.

### Воспроизведение

Python 3.12, версии проверенной среды: `tools/requirements-training.txt`. Сначала скачать upstream checkout, затем:

```sh
python -m pip install -r tools/requirements-training.txt
python tools/train_krsl.py --data ../krsl-recogniton/sign-prediction/V2-videos-5signers-isolated-signs-out/Absolute
```

Скрипт полностью повторяет split, обучение, отчёт, ONNX-экспорт и контрольные примеры. Результаты с иными версиями библиотек могут немного отличаться.

### Почему не перенесён старый Keras-чекпойнт

Он использует старый квантованный поток Relative-признаков с особенностями порядка рук и отсутствующих кадров. Проверялась численная конвертация LSTM в ONNX (отчёт `docs/krsl/legacy-conversion-report.json`, погрешность логитов менее 5e-6), но это не подтверждало работу современного захвата. На примере `spreadthesign-isolated-test-out/Relative/kto/kto.txt` он предложил другой класс. Этот чекпойнт **не является активной KRSL-моделью**. Вместо него используется новый прозрачный пилот на Absolute-координатах.

## РЖЯ — Easy Sign

https://github.com/ai-forever/easy_sign ; исходные `S3D.onnx`, `RSL_class_list.txt`, `configs/config.json`, `model.py`, `app.py` изучены. Commit и хеши зафиксированы в `third_party/model-manifest.json`.

S3D получает RGB/255 в порядке N,C,T,H,W, форма [1,3,32,224,224]. Исходный словарь содержит 1599 выходов, включая `no`; README описывает 1598 жестов. Это исходные веса авторов, команда их не переобучала. Порог 0,5 взят из конфигурации источника. Код/материалы Easy Sign распространяются с CC BY-SA 4.0; копия текста сохранена. Видеодатасет Slovo не скачивался и в архив не включён. Ссылки на Slovo и модели: https://github.com/hukenovs/slovo .

Русские подписи сохранены. Для 132 из 1599 выходов добавлены черновые казахские переводы, для остальных интерфейс явно показывает RU. Мы не заявляем полный перевод словаря или точность РЖЯ на своей камере.

## ASL — GestureSign

https://github.com/shashank11yadav/GestureSign ; исходный commit `ffc0578e68449676b6e9545da82092679914e8c8`.
250 ASL-классов, ONNX 5,6 MB и исходный landmark-пайплайн сохранены. Текстовые подписи переведены RU/KZ для всех 250 классов. Веса не изменены. Персональные жесты сопоставляются по embedding исходной ASL-модели и не становятся после этого обученным локальным переводчиком.

Исходные лицензии: код MIT; asl-signs/PopSign CC BY 4.0 по model card автора; MediaPipe Apache 2.0; ONNX Runtime MIT. См. `README_UPSTREAM.md` и notices.

## Другие найденные местные данные

- KRSL20 https://krslproject.github.io/krsl20/ — 20 исследовательских классов, 5200 видео по описанию авторов; актуальные ссылки Google Drive и условия доступа проверять перед скачиванием видео.
- FluentSigners-50 https://krslproject.github.io/FluentSigners-50/ , DOI https://zenodo.org/records/6043739 — непрерывная речь, 50 носителей. На Zenodo сейчас **Restricted**: нельзя заявлять автоматическую доступность файлов без разрешения. Статья с открытым доступом не снимает ограничения записи.
- KRSL-OnlineSchool https://krslproject.github.io/online-school/ — материал для следующего исследовательского этапа; не использован для текущей модели.

Новые личные видеозаписи в этой работе не собирались. Проверка с носителями, пользовательские согласия и NVDA — ещё предстоящая работа.

## Дактиль РЖЯ — Bukva

https://github.com/ai-forever/bukva (commit `174b7e3c04336e81ccbb19a4d8ad422fb29cfa6a`). Исходные веса `MobileNetV2_TSM.onnx` (9,1 МБ, метрика авторов 83,6 % на тесте по отдельным участникам) подключены без изменений. Вход [1,8,3,224,224] — 8 кадров (каждый второй кадр камеры), letterbox 224×224 с серыми полями 114, нормализация ImageNet mean/std, RGB. Выход — уже вероятности (softmax) для 34 классов: `no_event` и 33 буквы русского алфавита, включая динамические (Ё, Й, Щ, Ъ, Ц, З и др.). Казахские буквы Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І модель не знает. Модель не переобучалась; видеодатасет (~27 ГБ) не скачивался. Лицензия — переработка CC BY-SA 4.0 с указанием авторства, текст в `third_party/bukva/`.
