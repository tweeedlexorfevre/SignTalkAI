## Новый сборщик

Через отдельный Chrome с **искусственной камерой и искусственным landmark-worker** пройден полный сценарий: согласие, запрет камеры до согласия, заполнение меток, отмена отсчёта, захват, ручное сохранение, JSON-выгрузка, сохранность после перезагрузки, исправление метки, атомарная замена повтором, отказ при пустых руках, отзыв согласия, удаление. Ошибок JavaScript не обнаружено. Синтетические записи удалены из тестового контекста и не включены в пользовательский датасет.

Для экрана сборщика выполнен axe (WCAG 2 A/AA и 2.1 AA): 1280×900 RU, 375×812 KZ, 844×390 KZ в тёмном режиме, 375×812 RU с крупным текстом и повышенным контрастом. Нарушений и горизонтального переполнения в этих состояниях не обнаружено. Это не замена проверки NVDA и участия реального пользователя.

Повторить сценарий сборщика можно из корня проекта при запущенном сервере 5331:

```powershell
npx.cmd --yes --package @playwright/cli playwright-cli -s=signtalk open http://localhost:5331/ --browser chrome
npx.cmd --yes --package @playwright/cli playwright-cli -s=signtalk run-code --filename=tools/browser-checks/collector-smoke.js
npx.cmd --yes --package @playwright/cli playwright-cli -s=signtalk close
```

CLI загружается через npm, поэтому для этой проверки нужен интернет. Скрипт использует отдельный временный браузерный контекст с искусственными данными и не меняет пользовательское хранилище. `tools/browser-checks/camera-check.js` проверяет обычную доступную камеру без сохранения кадров; запускайте его только когда готовы включить камеру. Эти проверки дополняют `npm run test:e2e` и не входят в число девяти существующих E2E-сценариев.

## Что исправлено

1. Сбой `video.play()` теперь останавливает поток и показывает ошибку камеры.
2. Повторное включение камеры освобождает предыдущий поток. Старый callback или запоздалый bitmap не создаёт параллельный цикл; старые результаты worker не попадают в новую сессию.
3. Ошибка предварительной загрузки трекера обрабатывается даже при отказе в разрешении камеры.
4. KRSL и сборщик показывают статус трекинга при отключённом ASL-распознавателе.
5. Остановка KRSL-камеры отменяет незавершённую запись. РЖЯ освобождает отдельный поток также при `pagehide`.
6. Устранены замечания линтера, сохранена сверка KRSL-препроцессора с исходной контрольной записью.
