# Фактический вклад ИИ и команды — 17.11.2026

Стадия: создан и собран исходный прототип. Не путать с предыдущими документами стадии концепции.

Запрос команды: склонировать GestureSign, изучить нужные части, добавить переключаемый интерфейс RU/KZ, подобрать данные и отдельное местное/русское распознавание, выдать проект для Windows.

С помощью ChatGPT/Codex выполнены: чтение исходников и model card; поиск первичных источников; RU/KZ-тексты интерфейса и словарей; новый интерфейс SignTalk; подключение Easy Sign; разработка извлечения признаков и обучение KRSL10; экспорт в ONNX; протоколы тестирования, Windows-скрипты, документация.

Реальное самостоятельное решение команды в беседе: смена темы на жестовый язык и предложение добавить канал для незрячего человека. Авторство модели GestureSign и Easy Sign не переносится на команду. Новый код и KRSL10-модель подготовлены ИИ в рамках этого запроса; команда должна изучить, проверить, доработать и уметь объяснить их перед защитой.

Исправленные проблемы при реализации:

1. ASL нельзя превратить в местный язык заменой подписей — введены отдельные модельные профили.
2. Численно корректный перенос старой KRSL LSTM не доказал совместимость детектора. Старый чекпойнт исключён; вместо него обучен прозрачный десятиклассовый пилот.
3. Vite dev-сервер блокировал загрузку публичного ES-модуля ORT. Добавлена ограниченная выдача одного собственного runtime-файла; production использует обычные статические файлы.
4. Исправлены повторяющиеся React keys при переключении моделей.
5. Сохранение персональных жестов и исходные ASL-примеры отделены от реальной KRSL-модели.
6. У FluentSigners-50 на Zenodo обнаружен Restricted-доступ. Его данные не использованы и не обозначены как свободно скачанные.

Что ещё не сделано: живые тесты с носителями, тест Windows/NVDA/камеры, полноценные предложения, полный казахский перевод большого словаря Easy Sign, проверка рукописей переводов специалистом, подтверждение направления конкурса, финальная подпись AI-паспорта.

Основные артефакты проверки: `VALIDATION.md`, `WASM_CHECK.json`, `web/public/models/krsl/report.json`, `krsl/training-manifest.json`, `third_party/model-manifest.json`.

## Продолжение на Windows

Codex прочитал исходники и контекст, проверил архив и запуск Windows, реализовал отдельный RU/KZ-сборщик координат рук с согласием, локальным хранилищем и экспортом. Исправлены жизненный цикл камеры и обработка устаревших кадров, выполнены 150 unit-тестов, 9 E2E-сценариев, проверки WASM и сценарий сборщика на искусственных данных. Проверено открытие и остановка видеопотока Chrome; точность реальных жестов не измерялась. Новые модели не обучались. Реализация и документация этого этапа также подготовлены ИИ; это не самостоятельная авторская работа студентов. Подробности — WINDOWS_VALIDATION.md и DATASET_COLLECTION.md.
